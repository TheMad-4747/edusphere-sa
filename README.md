🎯 What is EduSphere SA?
EduSphere SA is a research-driven digital learning institute for South African learners in Grades 8–12. Every lesson is built on rigorous curriculum analysis before a single word is written.
We do not guess what learners need. We analyse: - Official DBE documents (CAPS, ATP, Examination Guidelines) - Past NSC exam papers and memoranda - Examiner reports identifying common errors - Learning difficulty research from South African classrooms
Then — and only then — do we write scripts, animate, and publish.
Our mission: Every lesson backed by research. Every concept exam-aligned. Every learner prepared.

🔬 Research Methodology
Phase 1: Document Analysis
For every subject, we collect and analyse: - CAPS (Curriculum and Assessment Policy Statement) - ATP (Annual Teaching Plan) - Examination Guidelines - SBA (School-Based Assessment) requirements - Past Question Papers (minimum 5 years) - Memoranda (official marking schemes) - Examiner Reports (identifying common errors and misconceptions)
Phase 2: Pattern Extraction
From the documents, we extract: - Frequently tested topics - High-priority concepts - Common learner mistakes (from examiner reports) - Assessment weightings - Historical changes in examination style
Phase 3: Teaching Strategy Design
For each concept, we design: - Recommended teaching sequence - Visual and animation ideas - Real-life South African examples - Formative assessment points - Recap and extension activities
Phase 4: Lesson Blueprint
Only after research is complete do we create: - Script outline - Character involvement - Scene locations - Quiz questions (Barrett’s Taxonomy aligned) - Worksheet structure
Phase 5: Production
•	Script writing
•	Animation
•	Voice-over
•	Worksheet creation
•	Quiz implementation
•	Quality assurance review

📝 The EduSphere Teaching Standard
Every lesson must satisfy these standards before publication:
Standard	Requirement
CAPS Aligned	Directly linked to official curriculum outcomes
ATP Aligned	Scheduled according to DBE Annual Teaching Plan
Exam Aligned	Reflects NSC examination style and cognitive levels
Age Appropriate	Language and concepts match grade level
South African Context	Names, places, and examples are locally relevant
Visually Engaging	Animation holds attention; no static lectures
Conceptually Accurate	Facts verified against official memoranda
Formative Assessment	Includes quiz with Barrett’s Taxonomy levels
Recap Included	Summarises key points at lesson end
Extension Activity	Homework challenge for deeper engagement
If a lesson does not meet all ten standards, it is not published.

🧠 The Internal Knowledge Base
We are building a searchable database where every concept is connected:
Example: Search “Metaphor” - CAPS references - ATP week and term - Previous NSC exam questions - Official memoranda - Common learner mistakes (from examiner reports) - Recommended animation approach - Existing EduSphere lesson link - Worksheet download - Quiz link
Example: Search “Quadratic Equations” - Same structured information, subject-specific
This ensures no lesson is ever created from memory. Everything is connected, referenced, and verifiable.

📊 Quiz Design Philosophy
All quizzes follow the DBE Barrett’s Taxonomy used in NSC examinations:
Level	Type	Weighting	Example Question Verbs
Low Order	Literal / Reorganisation	40%	Name, List, Identify, Describe, Summarise
Middle Order	Inference	40%	Explain, What reveals, What is the intention, How does it affect
High Order	Evaluation / Appreciation	20%	Do you think, Discuss critically, Comment on, Substantiate

View the Site Locally
1.	Download edusphere_sa_carrd_template_v3.html
2.	Double-click the file — it opens in your browser
3.	No server, no installation required

1.	Fork this repository
2.	Go to Settings → Pages
3.	Select Deploy from a branch → main → / (root)
4.	Your site is live at https://yourusername.github.io/edusphere-sa

2.	Drag and drop the HTML file
3.	Your site is live instantly with a free .netlify.app domain
